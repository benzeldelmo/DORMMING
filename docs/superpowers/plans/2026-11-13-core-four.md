# Core Four Cut Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut DormMing down to split bills, add shared expenses, record payments and view balances, in a clean OOP folder layout.

**Architecture:** Spring Boot backend in four layers (`model/`, `repository/`, `service/`, `controller/`) plus `config/`. React frontend with one page per function. In-memory storage, local login.

**Tech Stack:** Java 21, Spring Boot, Maven, JUnit 5 + AssertJ; React, Vite, TanStack Query, Tailwind, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-13-core-four-design.md`

## Global Constraints

- Only the four functions + register, log in, create/join/leave dorm, log out are reachable.
- No new dependencies. In-memory storage stays.
- One class per Java file, one job per class.
- Package root `com.dormming`; layers exactly `config`, `model`, `model.split`, `repository`, `repository.memory`, `service`, `service.exception`, `controller`, `controller.dto`, `seed`.
- Only `README.md` and `docs/DEFENSE-GUIDE.md` remain as `.md` files at the end.
- Light theme only; keep the olive/orange palette and Nunito + Google Sans.

## Review Focus

- Deleting an old expense that includes a member who has left: refused with a clear message (Task 3 test).
- Paying more than you owe: refused with "That's more than you owe (₱…)" (existing `PaymentServiceTest`, keep it).
- Leaving the dorm while owing or owed: refused (existing `DormServiceTest`, keep it).
- Receipt where items + extras ≠ total: refused (existing `SplitStrategyTest`, keep it).
- Logging in with different email case (`Benzel@Demo.ph`): works (Task 2 test in `AuthServiceTest`).
